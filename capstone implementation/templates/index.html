What is a Pushdown Automaton?

A Pushdown Automaton (PDA) is a finite state machine augmented with an external Stack Memory (Last-In, First-Out data structure).

  • 7-Tuple Definition: M = (Q, Σ, Γ, δ, q₀, Z₀, F)
  • Configuration (q, w, γ): Represents current state q, unread input string w, and current stack contents γ.
  • Transition δ(q, a, X) = (p, α): Reads symbol a (or ε), pops top symbol X from stack, moves to state p, and pushes string α onto stack.
  • Acceptance Condition: The input string is accepted if the PDA consumes all input symbols and ends up in an accepting state (q ∈ F).
